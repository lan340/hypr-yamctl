# hypr-yamctl 🎵❤️
### Управление и интеграция Яндекс Музыки для Hyprland & Waybar

Комплексная и отказоустойчивая интеграция **Яндекс Музыки** в панель **Waybar** и оконный менеджер **Hyprland** для Linux (CachyOS, Arch Linux, Fedora, Ubuntu и любых других дистрибутивов).

Позволяет ставить лайки без переключения фокуса окна, плавно регулировать звук, управлять воспроизведением хоткеями и наблюдать живой круговой прогресс трека в статусной панели.

---

## ✨ Возможности

* ❤️ **Служба лайков без потери фокуса окна:**
  * Определение статуса (лайкнут / не лайкнут) текущего трека в реальном времени.
  * Ставить/снимать лайк по хоткею `Super + ~` или кликом по сердечку в панели.
  * Работает через прямое взаимодействие с Chrome DevTools Protocol (CDP) браузерного ядра Electron.
* 🎧 **Название трека и круговой прогресс воспроизведения:**
  * Вывод названия песни и исполнителя в две строки (Pango Markup).
  * Динамический круговой SVG-индикатор с квантованием шага в 10% (0%–100%).
  * Клик: Play/Pause. Скролл колесом мыши: следующий / предыдущий трек. Клик средней кнопкой: Mute.
* 🔊 **Внутренняя громкость плеера:**
  * Индивидуальное управление звуком самого приложения Яндекс Музыки без изменения общей громкости системы.
  * Изменение шагом по 2% колесом мыши над иконкой звука или по хоткею `Super + Shift + Колесо`.
  * Интеллектуальный Mute с сохранением и восстановлением предыдущего уровня.
* 🖥️ **Надёжная мульти-мониторность (Concurrency Safe):**
  * Встроенный микрокэш (Request Coalescing 400 мс) объединяет одновременные опросы от нескольких панелей и мгновенно отдаёт ответ из памяти, не перегружая браузер.
  * Fail-Fast таймауты (`curl -m 1`) защищают рабочие потоки Waybar от зависаний.
  * Защита от гонки подключений WebSocket.
* 🛠️ **Интерактивный установщик с авто-зависимостями:**
  * Автоматически определяет пакетный менеджер (`pacman`, `yay`, `paru`, `dnf`, `apt`) и предлагает установить недостающие зависимости (включая Node.js и `ws`).
  * Позволяет выбрать целевые компоненты: **Waybar + Hyprland**, **Только Waybar** (для Sway, Niri, River и др.) или **Только Hyprland**.
  * Сканирует ваш `config`/`config.jsonc` Waybar с выбором секции (`modules-left`, `modules-center`, `modules-right`) и точной позиции.
  * Не ломает существующие конфиги (использует безопасные `include` и `@import`).
  * Полный автоматический бэкап перед любыми изменениями и скрипт чистого отката `uninstall.sh`.

## 🚀 Быстрая установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/hypr-yamctl.git
   cd hypr-yamctl
   ```

2. Запустите интерактивный скрипт установки:
   ```bash
   ./install.sh
   ```

3. Ответьте на несколько простых вопросов установщика:
   * Выберите секцию панели (`modules-left`, `modules-center` или `modules-right`).
   * Укажите позицию (например, после модуля `temperature` или `workspaces`).
   * Выберите клавишу-модификатор (`SUPER` или `ALT`).
   * Установщик создаст бэкап, скопирует иконки, пропишет модули и активирует фоновые службы systemd.

## ⌨️ Горячие клавиши по умолчанию (Hyprland)

| Сочетание | Действие |
| :--- | :--- |
| **`Super + ~`** (grave) | ❤️ Поставить / снять лайк текущему треку |
| **`Super + X`** | ⏯️ Воспроизведение / Пауза |
| **`Super + C`** | ⏭️ Следующий трек |
| **`Super + Z`** | ⏮️ Предыдущий трек |
| **`Super + Shift + Колесо Вверх`** | 🔊 Громкость Яндекс Музыки + |
| **`Super + Shift + Колесо Вниз`** | 🔉 Громкость Яндекс Музыки - |
| **`Super + Shift + Клик Колесом`** | 🔇 Заглушить (Mute / Unmute) |

*(Все горячие клавиши вынесены в отдельный файл `~/.config/hypr/yamusic.conf` и легко переназначаются).*

## 🧩 Взаимодействие с Waybar мышь/скролл

* **Кнопка Сердечка:**
  * `ЛКМ`: Переключить лайк.
* **Блок Инфо о треке:**
  * `ЛКМ`: Play / Pause.
  * `Колесо Вверх`: Следующий трек.
  * `Колесо Вниз`: Предыдущий трек.
  * `СКМ` (Средняя кнопка): Mute потока плеера в PipeWire.
* **Блок Громкости:**
  * `Колесо Вверх / Вниз`: Регулировка громкости с шагом 2%.
  * `ЛКМ`: Mute / Unmute.
  * `ПКМ`: Установить громкость на 50%.

## ⚙️ Архитектура

```
┌────────────────────────────────────────────────────────┐
│             Яндекс Музыка (Electron)                   │
│  (Запуск с --remote-debugging-port=9222 на CDP)       │
└──────────────┬──────────────────────────┬──────────────┘
               │ (CDP WebSocket)          │ (MPRIS D-Bus)
               ▼                          ▼
 ┌──────────────────────────┐   ┌──────────────────────────┐
 │ Демоны (systemd user):   │   │ playerctl / PipeWire:    │
 │ • ym-like-watch.js (:17311)│   │ • ym_playerctl           │
 │ • ym-vol-watch.js  (:17312)│   │ • ym_wpvol               │
 └─────────────┬────────────┘   └─────────────┬────────────┘
               │ (HTTP API, кэш 400мс)        │ (CLI)
               ▼                              ▼
 ┌─────────────────────────────────────────────────────────┐
 │               Waybar + Hyprland Binds                   │
 │  • Модули: custom/mpris_heart, ym_mpris, ym_volume      │
 │  • Сигналы мгновенного обновления: RTMIN+6, 7, 8        │
 └─────────────────────────────────────────────────────────┘
```

1. **`yandex-music`:** обёртка, запускающая приложение с флагами `--remote-debugging-port=9222` и выделенным профилем отладки.
2. **`ym-like-watch.js`:** легковесный Node.js демон (порт `17311`), считывающий DOM плеера через CDP. Осуществляет поиск кнопки лайка именно в нижнем контейнере активного плеера трека.
3. **`ym-vol-watch.js`:** демон громкости (порт `17312`). Каскадно регулирует уровень: через внутренний `externalAPI`, тег `<audio>` или ползунок слайдера.
4. **`ym_playerctl`:** умный фильтр инстансов MPRIS для Chromium-приложений.
5. **`ym_wpvol`:** точечная регулировка стрима аудио в PipeWire через `wpctl`.

## 🗑️ Удаление

Если вы решите удалить интеграцию, запустите скрипт удаления:
```bash
./uninstall.sh
```
Он аккуратно остановит службы, удалит исполняемые файлы, уберёт подключение модулей из Waybar/Hyprland и предложит при желании восстановить конфигурацию из сохранённого бэкапа.
